{% comment %} Homepage hero. Driven entirely by the `hero:` block in the including page's front matter, so the copy lives with the page rather than in this template. Expected shape: hero: eyebrow: short affiliation line name: display name (falls back to site.title) thesis: one-sentence research statement (Markdown allowed) levers: list of { label, text } pairs - the strands of the work facts: list of { label, value } pairs (value allows Markdown) `levers` is the page's signature block: the strands of the research, named and described, in place of a list of keywords. They follow a server's life, from designing it, to keeping it useful, to running it, so the order carries meaning and should be kept. Keep this to three, general, and free of specific results. It is an orientation to the work, not a summary of it; the news panel and the publications page carry the papers and the numbers.
