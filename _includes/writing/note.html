Parameters text Required. One or two sentences. If it needs a paragraph, it wants to be a footnote instead. mark Optional marker character. Defaults to an asterisk. Use this when the aside is a shrug, and a footnote (`[^1]`) when the aside is a source or an argument the reader might want to come back to. Footnotes get the same hover behaviour *and* a numbered entry at the end of the piece; a note like this deliberately leaves no trace after you stop pointing at it.
