--- layout: default --- {% comment %} A single writing entry. Deliberately not `single.html`. That layout carries the academic furniture - venue lines, recommended citation, author rail, related grid - which a blog entry has no use for, and its prose column is sized for a CV page rather than for reading. This owns its own container instead of fighting that one. Front matter it reads: title required strand an id from _data/writing.yml; falls back to the last strand there if missing or unrecognised standfirst one sentence under the title; also the index blurb tags list of free-form tags toc: true in-margin table of contents on wide screens updated: YYYY-MM-DD shown next to the date when an entry is revised mathjax: true already handled by _includes/head/custom.html header: image: card.png social card only. This layout never renders a hero, so `header.image` reaches nothing but the og:image tag in _includes/seo.html. Styles: _sass/_writing-post.scss · Script: assets/js/writing-post.js {% endcomment %} {% include base_path %} {% include writing/strand.html %}
{% comment %} The strand's colour is set once, on the shell, and inherited by everything in the entry - the breadcrumb, asides, the "keep reading" list. A component that wants the accent reads `var(--strand-color)` and never has to know which strand it is inside of. On the shell rather than on `.post`, because the contents rail is a sibling of the article, not a descendant: declared one level down, the rail's current-heading marker resolved `var(--strand-color)` to nothing and fell back to body ink. {% endcomment %}
